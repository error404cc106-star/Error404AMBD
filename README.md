# Web-Based Inventory and Appointment Booking Management System for AMDB Hub

## Project Overview
This repository contains the frontend implementation for the **Web-Based Inventory and Appointment Booking Management System for AMDB Hub**, built based on the approved Figma design. This milestone establishes the technical foundation, clean folder structure, and initial working pages for the project.

## Design System & Styling Guidelines
* **Colors:**
  * Primary Color: Light Gray (`#F8F9FD`)
  * Secondary Color: Dark Navy (`#111828`)
  * Accent Color: Soft Light Yellow / Cream (#FEF3C7 / #FFFBEB)
* **Typography:** Inter (Heading: Bold, Subheading: Semi-Bold, Body: Regular, Labels: Medium)
